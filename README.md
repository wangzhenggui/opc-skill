# opc-skill

一个基于《一人企业方法论》的可调用 Agent Skill，帮助分析和执行副业、一人企业、个人品牌、数字产品、独立开发、资产池、产品验证和产品化问题。

## 安装

将 `SKILL.md` 放入你的 Agent skills 目录，并按该 Agent 的规则重新加载 Skills。

## 使用

```text
请用 opc 分析我的副业想法。
```

或：

```text
请用 opc 帮我设计一个最低成本的 MVP 验证方案。
```

## 核心方法

- 从已有优势和副产品开始
- 用访谈、落地页、预售、众筹或 MVP 验证需求
- 计算真实贡献利润，而不是只看销售额
- 将工作流、知识、内容、用户和产品沉淀为资产
- 用产品池、用户池和共享基础设施降低边际成本
- 定期维护资产，降低单一平台和单一收入源风险
